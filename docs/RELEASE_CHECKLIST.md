# Before public GitHub upload

- [ ] Choose owner and repository name; complete author/publication metadata.
- [ ] Select a license for original SIVR additions and derived aggregates. Preserve the upstream MIT notice.
- [ ] Review backbone provenance and verify the exact experiment source if exact training replication is promised.
- [ ] Install full training dependencies in a clean environment and record a tested lockfile/CUDA build.
- [ ] Supply permitted frozen caches or a validated preparation recipe and data/model-provider references.
- [ ] Review illustrative development configurations against actual run manifests.
- [ ] Run documented CPU checks; optionally execute GPU smoke/checkpoint replay before claiming full reproduction.
- [ ] Exclude local paths config, credentials, raw restricted data, checkpoints and runtime outputs.
- [ ] Create a versioned release and archive permitted code/data in Zenodo if a DOI is desired.

You may first upload privately for collaborator review. No public upload is performed by this local packaging task. Root LICENSE is intentionally not invented for the authors.
